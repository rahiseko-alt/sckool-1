## 判定: 合格

主要画面に要件40の禁止モチーフは無く、幅375pxで横スクロールも出ない。

## 確かめた内容

### 1. 人（ユーザー本人）による確認 — 2026-09-02

- 市場一覧・商品詳細・ランキング・経営ダッシュボードの実画面と、幅375pxの市場一覧を見てもらった
- ユーザーの返答: **「実在のサービスに見える。これでよい」**、**「読める。問題ない」**（375px）

### 2. 機械での再確認 — 2026-09-05（全体照合の照合役）

幅375px（`viewport: 375`）で主要画面を開き、横スクロールの有無を測った:

| 画面               | scrollWidth / innerWidth | 横スクロール |
| ------------------ | ------------------------ | ------------ |
| 市場一覧           | 375 / 375                | 無し         |
| 商品詳細           | 375 / 375                | 無し         |
| 出品               | 375 / 375                | 無し         |
| 経営ダッシュボード | 375 / 375                | 無し         |

- ネパール語・タイ語でも全画面で横スクロール 0（`docs/audit-report.md` の 375px 監査と一致）
- 禁止モチーフ（黒板・鉛筆・ノート・学校/校章アイコン・子供向けイラスト・カラフルすぎる配色・
  ゲーム風UI・RPG風ゲージ・コイン演出・「勉強しましょう！」・PowerPoint 教材風）は、機械で見える範囲では
  該当なし。画面上の絵文字は言語切替の 🌐（地球儀）だけで、禁止一覧に当たらない
- 差し色は1色（`--accent: #2563eb`）・白背景。デザインの決まりは `docs/design.md`
