# 受け入れ記録: 日本語なしで完走できるか（受け入れ基準 I4、T041）

**deliverable**: 日本語以外の1言語だけで、説明なしにアカウント作成から商品登録と購入と
ダッシュボード閲覧まで到達できることを、人が実際に操作して確かめた記録。

---

## 判定: 合格

日本語を一切表示しない状態で、アカウント作成 → 商品登録 → 他社商品の購入 →
ダッシュボード閲覧まで到達できることを確認した。

## 確かめた内容

### 1. 人（ユーザー本人）による確認 — 2026-09-02

- 英語だけで「登録 → 控える → 出品 → 購入 → 経営」まで通した実画面をユーザーに見てもらった
- ユーザーの返答: **「送った画面で判断する。合格にしてよい」**（`/goal` の journey 確認）
- 同時に、デザインについても「実在のサービスに見える」「375px で読める」との合格を得ている
  （デザイン面は `docs/acceptance-design.md`）

### 2. 機械での再確認 — 2026-09-05（全体照合の照合役）

言語を英語に固定し、ブラウザ（Playwright）で最初から操作した結果:

| 工程                      | 結果                                              |
| ------------------------- | ------------------------------------------------- |
| アカウント作成 → ログイン | できた（`logged in as BUYER ... : true`）         |
| 他社の商品詳細を開く      | できた（`opened a non-own listing detail: true`） |
| 購入                      | できた（購入後に `"Purchase complete"` が表示）   |
| ダッシュボード閲覧        | できた                                            |

- UI の文言（ナビ・見出し・ラベル）に、ひらがな・カタカナは **0件**
  （ナビ: `Market / My products / Business / History / Ads / Quizzes / Ranking / Rules / Settings / Log in / Sign up`）
- 途中で手が止まる画面: **無し**

## 残る限界

- 市場の商品名に日本語が出ることがあるが、これは**生徒が入力した原文**で、訳が無ければ
  原文を出す仕様（受け入れ基準 I3）。UI の未翻訳ではない
- **英語以外の4言語（簡体字・ベトナム語・ネパール語・タイ語）は母語話者が読んでいない。**
  機械的な訳の過不足は 0 だが、訳文の自然さは人にしか判断できない
  （既知の積み残し。`docs/neglected-log.md`）。授業で使う前に、その言語を読む人に一度見てもらうのが望ましい
