# デザインの決まり

この仕組みの画面は、**実在するマーケットプレイスに見えること**を条件にしています
（要件39・41・43）。教材に見えた時点で不合格です。

このファイルは**判断の正本**です。色や余白を変えるときは、まずここを直してください。
実際の値は `apps/storefront/src/styles/tokens.css` にあり、このファイルの表と一致します。

---

## 1. 色

背景は**白**が中心。その上に薄いグレーで面を分け、文字はほぼ黒。
差し色は**1色だけ**にします。色数を増やすと一気に教材めいた見た目になります。

| 用途                 | 名前              | 値        | 使うところ                         |
| -------------------- | ----------------- | --------- | ---------------------------------- |
| 背景（一番下）       | `--bg`            | `#FFFFFF` | ページ全体                         |
| 背景（面を分ける）   | `--bg-subtle`     | `#F7F7F8` | カードの中、表の見出し行、入力欄   |
| 罫線                 | `--border`        | `#E4E4E7` | カードの枠、表の区切り、入力欄の枠 |
| 罫線（強め）         | `--border-strong` | `#D4D4D8` | 押せるものの枠                     |
| 文字（本文）         | `--text`          | `#18181B` | 見出しと本文                       |
| 文字（補助）         | `--text-muted`    | `#71717A` | 説明文、単位、日付                 |
| 差し色               | `--accent`        | `#2563EB` | 主なボタン、選択中のタブ、リンク   |
| 差し色（押したとき） | `--accent-hover`  | `#1D4ED8` | ボタンにカーソルを乗せたとき       |
| 差し色の上の文字     | `--accent-text`   | `#FFFFFF` | 主なボタンの文字                   |
| 良い変化             | `--positive`      | `#15803D` | 売上が増えた、入金                 |
| 悪い変化             | `--negative`      | `#B91C1C` | 残高不足、エラー、出金             |

**`--positive` と `--negative` は数字の増減にだけ使います。** 装飾には使いません。
色だけで意味を伝えないこと（色が分からない人にも読めるよう、必ず文字か記号を添える）。

## 2. 余白

**4の倍数**で刻みます。中途半端な値を使うと画面ごとにばらつきます。

| 名前      | 値     | 使うところ                       |
| --------- | ------ | -------------------------------- |
| `--sp-1`  | `4px`  | 文字と記号のあいだ               |
| `--sp-2`  | `8px`  | 小さな部品の内側                 |
| `--sp-3`  | `12px` | 入力欄の内側                     |
| `--sp-4`  | `16px` | カードの内側、部品どうしのあいだ |
| `--sp-6`  | `24px` | カードどうしのあいだ             |
| `--sp-8`  | `32px` | 節どうしのあいだ                 |
| `--sp-12` | `48px` | ページの上下の余白               |

**カードの内側は最低 `--sp-4`（16px）。** 詰めると安っぽく見えます。

## 3. 角の丸みと影

| 名前            | 値                           | 使うところ           |
| --------------- | ---------------------------- | -------------------- |
| `--radius-sm`   | `6px`                        | 入力欄、小さなボタン |
| `--radius-md`   | `10px`                       | カード               |
| `--radius-lg`   | `14px`                       | 大きな枠、写真       |
| `--shadow-card` | `0 1px 2px rgba(0,0,0,0.04)` | カード               |

**影は薄く1段だけ。** 濃い影や複数段の影はゲーム風に見えます。

## 4. 文字

| 用途           | 大きさ | 太さ | 行の高さ |
| -------------- | ------ | ---- | -------- |
| 大見出し       | `28px` | 600  | 1.3      |
| 見出し         | `20px` | 600  | 1.4      |
| 小見出し       | `16px` | 600  | 1.5      |
| 本文           | `14px` | 400  | 1.6      |
| 補助           | `13px` | 400  | 1.5      |
| **数字（大）** | `32px` | 600  | 1.2      |

字体は端末が持っているものを使います（6言語ぶんの字体を配ると重くなるため）。

```
system-ui, -apple-system, "Segoe UI", "Noto Sans JP", "Noto Sans SC",
"Noto Sans Thai", "Noto Sans Devanagari", sans-serif
```

**数字は必ず等幅の字形にします**（`font-variant-numeric: tabular-nums`）。
桁が揃わないと、残高や売上が並んだときに読み違えます。

## 5. 金額の書き方

```
96,500 MP
```

- 3桁ごとに区切る
- 単位は `MP`。数字との間に半角の空きを1つ
- **記号（¥ や $）は使わない。** 現実のお金ではないため
- 小数は使わない（価格は1MP以上の整数、受け入れ基準 C3）

## 6. 禁止するもの（要件40）

**下のどれか1つでも画面に出たら不合格です。**

| 禁止                           | なぜ                                       |
| ------------------------------ | ------------------------------------------ |
| 黒板                           | 学校用教材に見える                         |
| 鉛筆                           | 同上                                       |
| ノート                         | 同上                                       |
| 学校の建物・校章のアイコン     | 同上                                       |
| 子供向けのイラスト             | 対象は専門学校生以上。子供扱いに見える     |
| カラフルすぎる配色             | 差し色は1色だけ                            |
| ゲーム風の UI                  | 経営シミュレーションであってゲームではない |
| RPG 風のゲージ                 | 同上                                       |
| コインが飛び散る演出           | 同上                                       |
| 「勉強しましょう！」の呼びかけ | 教材に見える                               |
| PowerPoint 教材のような画面    | 同上                                       |

**紙吹雪・拍手・効果音の類も入れません。** 上の一覧に無くても、
「褒めて励ます」ための演出はすべて同じ理由で外します。

## 7. 画面の言葉づかい

内部の名前は英語で統一し、画面表記は辞書で差し替えます（受け入れ基準 J2）。

| 内部の名前      | 画面（日本語の既定） |
| --------------- | -------------------- |
| `Participant`   | 生徒                 |
| `Organization`  | 学校                 |
| `Administrator` | 先生                 |

**コードに「生徒」「先生」と直接書かないこと。** 企業研修に売るときは
辞書だけを差し替えて「受講者」「講師」にします。

## 8. 幅

- 幅 **375px** で横スクロールが出ないこと（受け入れ基準 J3）
- 本文の最大幅は `1200px`。それ以上は左右に余白を置く
- 表が入りきらないときは、**表だけ**を横スクロールさせる（ページごと流さない）

## 9. 確かめ方

この決まりを守れているかは `T042` で人が見て確かめます。手順は
`docs/acceptance-design.md`（`T042` で作る）に置きます。
